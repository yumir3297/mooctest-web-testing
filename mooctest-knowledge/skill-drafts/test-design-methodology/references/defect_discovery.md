## 1. 三层观察

按表现层 / 业务层 / 数据层看，页面只能直接看到表现层 `[MY] ch10 p.195–198`。

| 层 | 可观察 | 典型缺陷 |
|---|---|---|
| 表现层 | 链接、导航、表单布局、文案、图片、分页、排序 | 死链、错位、文案缺字、排序无效、空态缺失 |
| 业务层 | 计算、权限、流程、事务、并发 | 金额算错、越权可见、流程可跳步 |
| 数据层 | 展示一致性、刷新后状态 | 列表≠详情、刷新回退、重复记录 |

## 2. 规则

### DEF-01 输入异常
`[MY] ch4 p.81`；`[EI] A2`（Zero/One/Many、Some/None/All、Violate Data Format）
观察：空、仅空格、0、负数、超长、错误字符集、前后空格、全角半角、emoji、粘贴超长。
判据：有明确提示且页面可用；不得 500/白屏/静默改写。
易误判："按了没反应"可能是有意校验时机。

### DEF-02 参数冲突
`[MY] ch4 p.61`；`[EI] A2`（Constraints）
观察：起>止、下限>上限、互斥项同选、必填与可选冲突。
判据：前端阻止或明确提示；不得静默取其一。

### DEF-03 边界条件
`[MY] ch4 p.56–57`
观察：按 `MS-01` 选定的覆盖项（2 或 3 项/边界），档位切换点，"满 X"是否含 X，小数进位。
判据：边界两侧行为符合需求表述；比较符错误是本类最高发缺陷。

### DEF-04 顺序与状态
`[ISTQB] §4.2.4`；`[EI] ch8 p.88–99`
观察：跳步、逆序、重复触发、中途返回、超时重试。
判据：非法顺序被拒绝；重复触发不产生重复业务记录。

### DEF-05 页面状态不一致
`[EI] ch5 p.66`
观察：列表 vs 详情、明细之和 vs 总额、筛选数 vs 分页总数、刷新前后。
判据：同一事实多处展示必须一致。

### DEF-06 表单与动态交互
`[MY] ch10 p.204–205`；`[EI] A2`
观察：前端校验被绕过、联动字段旧值残留、异步期间重复提交、弹窗关闭后状态残留、联想选错值。
判据：前端校验不能作为唯一防线；交互后状态自洽。

### DEF-07 导航、会话与重复提交
`[EI] A2 p.166`（Back/Forward/History、Bookmark It）
观察：回退再前进是否重复提交；直接访问受保护 URL；刷新结果页是否重复下单；404/坏链/坏图/部分加载。
判据：回退刷新不改变业务结果；受保护资源不得匿名访问。

### DEF-08 测试假设导致的假缺陷
`[ENG]`；与 `ORA-04`、`ORA-09` 配套
观察：这条预期来自哪里；是否把行业惯例当需求；是否把别的产品行为当标准。
判据：无出处规则必须标为假设，不得用于判定失败。

### DEF-09 越权与安全
`[MY] ch10 p.196–198`（安全为 Web 关注点）；具体检查项 `[ENG]`
观察：改 URL 参数看他人订单、未登录访问详情、前端隐藏但接口可调。
判据：越权必须服务端拒绝；仅前端隐藏不算修复。
限制：赛题限定单账号时只能记为范围外风险。

### DEF-10 三态定性
`[EI] ch5 p.62–63`；`ORA-08`
有依据且违反 → 缺陷；无依据但违反 Never/Always → 缺陷候选；无依据且不违底线 → 疑点；不可复现 → 记环境与次数，不定性。

## 3. 可勾选清单

**输入**：空/空格/0/负数/超长/特殊字符/全角半角/emoji/粘贴超长/trim 行为
**组合**：起止倒置/互斥同选/多条件致金额或状态异常
**边界**：`MS-01` 覆盖项/档位切换/满减临界/精度舍入
**流程**：跳步/逆序/重复提交/中途返回/会话过期/不可逆动作二次确认
**一致性**：列表 vs 详情/明细之和 vs 总额/筛选数 vs 分页总数/刷新回退
**交互**：异步重复点击/联动旧值/弹窗残留/前端校验绕过
**导航会话**：回退重放/受保护 URL 匿名访问/404/坏链/部分加载
**假设**：每条预期可溯源/无出处规则已标假设

## 4. 使用约束

1. 清单用于"探索与补充"，不替代 `MS-01..MS-05` 的覆盖项设计。
2. 清单项命中后仍需 `test_oracle.md` 的判据才能升级为缺陷。
3. 本清单中 `[ENG]` 条目不得作为评定"产品不合规"的唯一依据。
