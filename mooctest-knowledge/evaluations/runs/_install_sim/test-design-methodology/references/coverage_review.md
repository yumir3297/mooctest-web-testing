## 0. 评审口径

- 评审与动态执行互补：评审在执行前发现逻辑与规格问题，动态测试只能暴露症状 `[MY] ch3 p.21–22`。
- 评审按清单逐项核对，不凭印象通读 `[MY] ch3 p.23`。
- Web 赛道无源码，**不以语句/分支覆盖率作为交付指标**；覆盖检查改用"需求门禁 + 覆盖项"双轨 `[S-01]`。

## 2. 规则明细

### REV-00 覆盖门禁口径（v0.2 新增）
- **Source**：`[ENG]`；与 `[MY] ch2 p.13–14`（无预期即无效用例）一致
- **Trigger**：统计覆盖率前
- **Decision**：
  1. 分母 = `可测` 需求数（`需澄清`/`不可执行`/`非测试范围` 不计入分母，但必须单列）；
  2. 分子 = 拥有 `SPEC/DERIVED/PARTIAL` 判据的用例所覆盖的 `可测` 需求数；
  3. `ORACLE-UNKNOWN` 与观察项不计分子；
  4. 同时报告"需求关联度"与"可验证用例覆盖率"两个数。
- **Validation**：分母口径可复算；缺口清单与分母差额一致
- **Exceptions**：赛题明确排除的功能不计入分母，须注明排除依据

### REV-01 需求遗漏检查（v0.2 修正）
- **Source**：`[S-01]`（充分性）；`MS-00` 分诊
- **Trigger**：提交前
- **Decision**：
  1. 每个 `可测` 需求 ≥1 条**有判据**的正式用例；
  2. 需求中的"应当/必须"逐句核对，不按段落；
  3. `需澄清`/`不可执行`/`非测试范围` 各自列入缺口清单并写明原因；
  4. 页面存在但需求未提的功能，单列"补充覆盖"，标注无需求依据。
- **Validation**：`可测` 遗漏数 = 0；观察项未被算作有效业务用例
- **Exceptions**：赛题排除项不计遗漏

### REV-02 覆盖项检查（v0.2 修正，取消四固定点）
- **Source**：`[MY] ch4 p.51–57`；`[ISTQB] §4.2.1/§4.2.2/§4.2.3/§4.2.4`
- **Trigger**：每个含输入的字段、每条业务规则、每个状态机
- **Decision**：按覆盖项逐项核对——
  1. 每个有效分区 ≥1；
  2. 每个无效分区 ≥1 条**独立**用例（不与其他无效分区合并）；
  3. 每个边界按其选定 BVA 准则（2-value 或 3-value）产生 2 或 3 个覆盖项，全部命中；`N/A` 需写明原因；
  4. 每条可达判定规则列 ≥1；
  5. 每条合法状态迁移 ≥1，关键非法迁移 ≥1；
  6. 组合覆盖：每个参数对 ≥1（若启用）。
- **Output**：覆盖项检查表（覆盖项 / 是否命中 / 用例 ID）
- **Validation**：覆盖项总数可数、可复算，不以"用例条数"代替
- **Exceptions**：无可表示邻近值、页面无法输入、赛题限定样例值 → 记 `N/A` 并注明，不得凭空造值
- **V0.1 弃用**："每边界 min-1/min/max/max+1 必须齐全"作废

### REV-03 重复与无意义用例识别
- **Source**：`[ENG]`；分区"减少用例数"原则 `[MY] ch4 p.49–50`
- **Decision**：判定重复——① 同一分区换值且预期相同；② 同一判定列换文案；③ 同一迁移换用户名；④ 预期为"页面正常显示"且无具体断言
- **Validation**：删除后覆盖项不出现新缺口
- **Exceptions**：为覆盖不同数据组合而保留的，须在目的栏写明差异

### REV-04 预期依据检查
- **Source**：`[MY] ch2 p.13–14`；`[EI] ch5 p.68`；`test_oracle.md`
- **Decision**：① 无 `oracle_type` → 不合格；② SPEC 但无需求编号 → 不合格；③ DERIVED 但无推导链 → 不合格；④ UNKNOWN 却写了业务值 → 不合格（且不得存在于正式用例集）；⑤ 判据变更无证据 → 不合格
- **Validation**：虚构预期数 = 0

### REV-05 测试目的明确性
- **Source**：`[ENG]`；反面依据"无目的用例等同随机测试" `[MY] ch4 p.41`
- **Decision**：标题必须回答"验证什么风险/规则"；出现"测试功能是否正常""验证页面"即不合格；一条用例一个主验证点
- **Validation**：遮住内容只看标题能否复述验证点

### REV-06 可执行性检查
- **Source**：`[S-01]`（可复现性）
- **Decision**：① 前置可达；② 每步有明确元素与动作；③ 无"点击适当按钮"类描述；④ 依赖外部服务时标 `BLOCKED` 或转 `不可执行`
- **Validation**：他人按步骤可无口头补充复现

### REV-07 通过/失败可判定性
- **Source**：`[MY] ch2 p.13–14`；`ORA-03/04`
- **Decision**：必须有可观察的通过条件与失败条件；异步场景写明等待条件与超时；`PARTIAL` 用例必须写明"只验证哪一部分"
- **Validation**：每条都能写出"若 X 则失败"

### REV-08 边界语义检查（v0.2 改写）
- **Source**：`[MY] ch4 p.56–57`（边界比较符是高发缺陷）；`[ISTQB] §4.2.2`
- **Decision**：核对——① 开闭区间语义；② 单位一致（kg/g、元/分）；③ 日期时区与当天 00:00/23:59；④ 小数精度与步进；⑤ 多字段边界不混用；⑥ 覆盖项取值在页面上真实可表示
- **Validation**：每个覆盖项都能说出"为什么取它"
- **Exceptions**：开闭语义未定义 → 标 `需澄清`，不擅自选一种

### REV-09 覆盖度自评与缺口输出
- **Source**：`[MY] ch4 p.83`；`[S-01]`
- **Decision**：输出双指标、覆盖项达成率、重复数、虚构预期数、`BLOCKED` 数、缺口清单
- **Validation**：所有数字可复算
