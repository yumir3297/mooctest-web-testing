## 4. 引用纪律

1. 规则里只写"方法名 + 自写结论 + 页码"，不复制原文段落。
2. 页码未核验的引用必须标 `[页码未核验]`，不得省略。
3. 教材 PDF 属个人合法获取的私有副本，**不得**随 Skill 分发、不得进入公开仓库。
4. 需要原文核对时，读取仓库内 `mooctest-knowledge/sources/chapter-text/`，按 `[printed p.N]` 锚点只读目标页。
