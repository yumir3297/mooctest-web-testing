## 2. 等价类划分（新增输入）

| 输入域 | 有效等价类 | 无效等价类 |
|---|---|---|
| 非空文本 | 普通中英文、数字、符号 | 空字符串、纯空白 |
| 长度 | 1 字符、常规长度、200 字符 | 超长文本（当前无明确上限，记录为风险） |
| 特殊字符 | `<`、`>`、`&`、引号、HTML 片段 | 可执行脚本片段（应被转义） |
| 前后空白 | 文本前后空格（应 trim） | 仅空白（应拒绝） |

## 3. 边界值

| 边界 | 取值 | 预期 |
|---|---|---|
| 空输入 | `""` | 不新增 |
| 纯空白 | `"   "` | 不新增 |
| 最小有效长度 | `"A"` | 新增成功 |
| 长文本 | 200 个 `B` | 完整保存 |
| 计数边界 | 0、1、2 条 | 状态栏隐藏/单数/复数 |
| 列表边界 | 0 条、1 条、多条 | 删除/清除/过滤不误删 |

## 4. 判定表：过滤器与完成状态

| 条件/动作 | 规则 1 | 规则 2 | 规则 3 |
|---|---|---|---|
| 存在未完成项 | 是 | 否 | 是 |
| 存在已完成项 | 否 | 是 | 是 |
| 选择 All | 显示全部 | 显示全部 | 显示全部 |
| 选择 Active | 显示未完成 | 空列表 | 仅未完成 |
| 选择 Completed | 空列表 | 显示已完成 | 仅已完成 |

## 5. 状态迁移：单条待办

`不存在 → 未完成`（新增）  
`未完成 ↔ 已完成`（勾选/取消）  
`未完成/已完成 → 编辑中`（双击）  
`编辑中 → 未完成/已完成`（回车保存或失焦）  
`未完成/已完成 → 不存在`（删除或清除已完成）
