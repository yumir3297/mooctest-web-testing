## 1. 需求拆解

| 编号 | 需求/行为 | 可观察结果 | 风险 |
|---|---|---|---|
| R1 | 新增待办 | 列表出现文本，计数增加 | 高 |
| R2 | 完成/取消完成 | 复选框状态、计数、过滤器结果变化 | 高 |
| R3 | 编辑待办 | 双击后输入，回车保存 | 中 |
| R4 | 删除待办 | 列表移除，空列表时状态栏隐藏 | 中 |
| R5 | 空/空白输入 | 不新增待办 | 高 |
| R6 | 输入长度边界 | 1 字符和长文本可保存 | 中 |
| R7 | 特殊字符/HTML 注入 | 按纯文本展示，不执行脚本 | 高 |
| R8 | 计数单复数 | 1 item left / N items left | 低 |

## 2. 等价类划分（新增输入）

| 输入域 | 有效等价类 | 无效等价类 |
|---|---|---|
| 非空文本 | 普通中英文、数字、符号 | 空字符串、纯空白 |
| 长度 | 1 字符、常规长度、200 字符 | 超长文本（无明确上限，记录为风险） |
| 特殊字符 | `<`、`>`、`&`、引号、HTML 片段 | 可执行脚本片段（应被转义） |
| 前后空白 | 文本前后空格（应 trim） | 仅空白（应拒绝） |

## 3. 边界值

| 边界 | 取值 | 预期 |
|---|---|---|
| 空输入 | `""` | 不新增 |
| 纯空白 | `"   "` | 不新增 |
| 最小有效长度 | `"A"` | 新增成功 |
| 长文本 | 200 个 `B` | 完整保存 |
| 计数边界 | 0、1、2 条 | 状态栏隐藏 / 单数 / 复数 |
