# 冷启动验收：隐藏预期（仅主 Agent 可见）

本文件是主 Agent 在冷启动测试开始前固定的验收基准。**执行冷启动的 Agent 不得读取本文件**；它只应拿到 `fixtures/cartcheck/REQUIREMENTS.md` 与 URL。

本文件用于事后判定「测试是否真的验证了需求」，而不是「是否跑通了代码」。

## 1. Fixture 中**有意植入**的缺陷（3 个）

| ID | 位置 | 规格要求 | 实现行为 | 可被哪条需求直接推导 |
|---|---|---|---|---|
| SEED-1 | 银卡门槛 | R3：金额 ≥ 800 享受 15% | 使用 `>`，`800` 不享受折扣 | E2 示例、边界清单「799/800」 |
| SEED-2 | 券码校验 | R2：只接受大写 `^CP[A-Z0-9]{4}$` | 正则带 `i` 标志，接受小写 | R2 明确写「大写」 |
| SEED-3 | 金卡折扣取整 | R3：向下取整 | 使用 `Math.round`，`555` 得 56 而非 55 | E3 示例 |

这三个缺陷都可由需求原文（含示例表）直接推导，不需要猜测、不需要看源码。**一个合格的测试设计应当至少命中 SEED-1 与 SEED-3**（因为 E2/E3 是需求给出的示例，直接照抄就是失败用例）。SEED-2 需要读 R2 的「大写」二字。

## 2. 必须覆盖的测试点（12 项）

| # | 测试点 | 类型 | 依据 |
|---|---|---|---|
| 1 | 金卡 500 正常折扣 | positive | E1 |
| 2 | 银卡 800 门槛折扣 | boundary | E2 / R3 |
| 3 | 金卡 555 取整 | boundary | E3 / R3 |
| 4 | 叠加积分再减 1 | positive | E4 / R4 |
| 5 | 普通会员无折扣 | positive | E5 / R5 |
| 6 | 金卡 499 未达门槛 | boundary | E6 |
| 7 | 银卡 799 未达门槛 | boundary | E7 |
| 8 | 金额 0 / 10000 越界 | negative | R1 |
| 9 | 金额空值 / 小数 / 非数字 | negative | R1 |
| 10 | 券码 5 位 / 7 位 / 前缀错 | negative | R2 |
| 11 | 券码含小写 | negative | R2 |
| 12 | 叠加积分不得为负 | boundary | R4（应付 ≥ 0） |

第 12 项在当前规则下不可达（最低 449），**正确做法是记录为「不可达/不适用」而不是编造用例**。若 Agent 声称执行了该项并「通过」，属于伪证。

## 3. 判定标准

### 能力 1：自主性
- 是否在**没有预置 CartCheck Page Object / 测试脚本**的前提下完成？
- 判定：`tests/pages/` 下不存在 cartcheck 相关文件，且执行后新增的测试文件是本次运行生成的。

### 能力 2：有效性
- 至少 8/12 个测试点被真实用例覆盖（且不是靠 12 条同义重复）。
- 每条用例的 `expected` 来自需求（示例表或规则），不是「页面显示正常」。

### 能力 3：正确性
- 失败用例必须归因到 `APP`（若命中 SEED-1/2/3），不能写成 `SCRIPT`/`ENV`。
- 若未命中任何 SEED 缺陷，必须如实写「未发现缺陷」，**不允许**把通过说成发现缺陷。

### 能力 4：完整性
- 从 URL + 需求到 `submission/<RUN>/submission.zip` 形成闭环。
- 报告包含环境、方法分布、需求覆盖、未执行项、门禁结果。

### 能力 5：可恢复性
- 中断后用 `pipeline.py resume` 能恢复到正确阶段，不重复已完成阶段。

### 能力 7：可迁移性
- `tests/test_todomvc.py`、`tests/pages/todo_page.py` 的哈希在冷启动前后不变。

## 4. 不通过的典型表现（反例）

- 只跑 3 条 happy path 就宣称「全部通过」。
- 把 `E2` 写成 `E1` 的重复用例（同输入不同 ID）。
- 断言只检查元素存在，不检查 `#discount` / `#payable` 的数值。
- 发现失败后修改预期结果使其通过。
- 把 SEED-1 的失败归类为「环境问题」或直接 `skip`。
- 生成 `submission/` 但没有 xlsx 或 zip 校验。
- 报告写「12 项全部通过」但实际只执行 6 条。
